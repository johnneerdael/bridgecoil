Depth without a command wall

App names and actions come first. Package IDs, detected capabilities, command details, and output expand only when needed.

Honest availability

Available, needs setup, unsupported, and not yet checked are different states. A button capture does not imply it can be remapped.

One product, two phones

The same navigation on Android and iOS. Native pickers and network permissions belong to each platform. A background disconnect is visible, never silent success.

Interaction logic

Guide the work, keep the detail.

Connect

TV setup guide → discovery or address → pairing code / TV approval → connect → inspect capabilities. Pairing and connection use separate endpoints.

Apps

Names + icons → filter → details → named action → effects and recovery → verify state. Bulk changes use a review list with per-app results.

Buttons

Check capture support → listen → identify source → choose gesture and installed app → test → save. Persistent mappings use a detected native method or a TV-side runtime with guided setup.

Launcher

Choose an eligible launcher → launch test → request default → test Home → optionally disable stock launcher as a separate reviewed action.

Coverage, not a release commitment

Detailed flows still to review

Device

Saved TVs, pairing, connection, profiles, model and OS, capability checks, storage, connection health, restart, recovery.

Apps

Installed and system packages, APK / split APK install, launch, force stop, disable / enable, remove for a profile, reinstall when possible, permissions, app links, export APKs.

Remote

D-pad, media and volume, text entry, app shortcuts, key learning, source identity, press gestures, mappings, Shizuku/Termux setup, startup tests and restore.

Tools · Personalize

Launcher selection, stock launcher controls, supported display / density settings, animation settings, audio and input inspection.

Tools · Files & diagnostics

Browse permitted folders, upload / download, screenshot, recording where supported, filtered logs, bug reports, processes, memory and network inspection.

Tools · Advanced + History

Interactive shell, saved actions, port forwarding / reverse where supported, reviewed action sequences, result output, exportable change records, available recovery actions.

Scope rule: expose every supported capability in a browsable category. Keep unsupported actions discoverable with a reason and a next step. “No command typing” does not mean zero text entry: pairing codes, addresses, filenames, and optional search still need inputs.
