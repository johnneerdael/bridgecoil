# Bridgecoil website assets

Original artwork, semantic tokens and typefaces from Bridgecoil Brand Kit v1.0 (30 October 2026), supplied for this project. Logo paths and marketing PNGs are copied unchanged. Fonts are served locally; their OFL licenses are beside them in `fonts/`.

`marketing/bridgecoil-readme-dark.png` is also the release banner. Keep its 1600 × 480 proportions. The UI compositions in the kit are design references, not application screenshots, and are deliberately not published as product captures.
