05 / BEFORE YOU START

A little context.

Compatibility & limits →
Do I need root or a computer?

Bridgecoil speaks ADB directly to supported TVs over the local network. Normal setup uses Wireless debugging and does not require root or a computer. Persistent mappings need additional tools on the TV; Bridgecoil guides their installation and checks each step.

Can every remote button be remapped?

No. Power, voice and some vendor buttons may never reach the available input path. With the current non-root listener, the original action can happen before the mapped action. Test each button on your TV.

What gets installed on the TV?

Advanced mapping setup uses Shizuku-Next or Porter, Termux and Termux:Boot. Bridgecoil checks expected signing certificates before installing helper downloads. Basic app management and remote controls do not need that entire toolkit.

Does it work over Ethernet?

Wireless debugging and helper startup depend on the TV’s Wi-Fi behavior. A wired connection can prevent the helper from restarting automatically. Enable Wi-Fi or start it again from Bridgecoil after a restart.

Is every change undoable?

No. History offers recovery where the operation supports it. Re-enabling an app is different from recovering deleted files or app data. Read the specific change and recovery limits before applying it.
