# Which buttons can be remapped

<p class="lead">A button can be remapped if Android can see it. Tap **Listen** and press it to find out.</p>

| Button | Usually works? |
|---|---|
| Streaming shortcuts, such as Netflix or YouTube | Yes |
| Colored and number buttons | Yes |
| Arrows, OK, Back, Home | Yes, though you'd lose them as normal buttons unless you use a hold |
| Volume | Often. Some TVs handle it before Android sees it |
| Power | No |
| Voice or Assistant | Often no |
| Some TV-brand buttons | Often no |

"Power, voice and some TV-brand buttons never reach apps, so they can't be remapped." Those are handled by the TV's own hardware or firmware.

Bluetooth and infrared buttons both work if they reach Android. Some remotes send one button on two input devices, in which case **Listen** shows two rows. Choose either, and test it.

Android 10 and older TVs show keys as raw numbers rather than names. That's only a display difference.
