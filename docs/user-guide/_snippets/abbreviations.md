*[ADB]: Android Debug Bridge, the tool Android provides for managing a device from another device
*[APK]: Android package, the file an Android app is installed from
*[TLS]: Transport Layer Security, the encryption used by wireless debugging
*[mDNS]: Multicast DNS, how devices announce services on a local network
*[UAD]: Universal Android Debloater, the community list behind Bridgecoil's ratings
*[SDK]: Android's internal version number, such as 34 for Android 14
