# Undo a change

<p class="lead">Most changes can be reversed from History.</p>

1. Open **History** and tap the change.
2. Tap **Review recovery**.
3. Read the review, tick the box and tap **Apply change**.

You need to be connected to the same TV and profile. **Review recovery** appears only if the change was verified and Bridgecoil knows how to reverse it.

## What can be undone

| Change | Undo |
|---|---|
| Disable, Enable, Default enabled state | Returns to the previous state |
| Permissions and special access | Returns to the previous value |
| TV settings | Returns to the previous value |
| Switching launcher | Turns the old launchers back on and makes the old one the default |
| Force stop, Clear cache | Nothing to undo |
| Remove from profile | Use **Restore existing package**. The data is gone |
| Clear app data | Can't be undone |
| APK install | Not in History. Remove the app instead |

## If undo is refused

"The TV state changed after this operation." means something else changed the same thing since. Bridgecoil won't guess, so check the current state and make a new change.

A bulk change has one row per app, and each is undone separately. Undo still respects the protection on Unsafe apps.
