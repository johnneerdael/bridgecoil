# Install a launcher

<p class="lead">Home app offers four launchers and fetches the latest version from each developer. You can also install any other launcher from a file.</p>

| Launcher | Good for | Android | Source |
|---|---|---|---|
| Backdrop | A cinematic look with custom app rows | 6 or later | [johnneerdael/backdrop-launcher](https://github.com/johnneerdael/backdrop-launcher) |
| Projectivy | Heavy customization, with many options | 6 or later | [spocky/miproja1](https://github.com/spocky/miproja1) |
| Monet | Dynamic colors | 8 or later | [Klevico/Monet-Launcher](https://github.com/Klevico/Monet-Launcher) |
| AT4K | Another Android TV launcher to try | 8.1 or later | [avadhesh18/at4k](https://github.com/avadhesh18/at4k) |

Tap **Install** next to one. Bridgecoil downloads it from GitHub, [checks its signature](../how-it-works/how-downloads-are-checked.md) and installs it. You'll see each stage. Look at the TV in case Play Protect asks you something.

Installing doesn't change your home screen. Once it's installed, **Try it** appears. See [Replace your home screen](replace-your-launcher.md).

Installs happen right away with no review, and they aren't recorded in History. To remove a launcher, use [Remove from profile](../apps/turn-off-or-remove-an-app.md).

## Install a launcher from a file

**Install from a file** opens [Install an app](../apps/install-from-a-file.md), so you can use any launcher you have as an APK. That covers one you built yourself or a version a developer sent you.

Once installed, a launcher that isn't on the list appears with its package name and **Try it**.

A file signed by someone else can't be installed over a launcher that's already there, because Android refuses it. Remove the installed one first. That deletes its settings.

If you're offline, the list still works without version numbers.
