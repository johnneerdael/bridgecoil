# Report a problem

Open an [issue on GitHub](https://github.com/johnneerdael/bridgecoil/issues). These help:

- Your TV's model and Android version, from **Device details**
- Your phone and the app version
- What you did, and what you expected
- The message, with the text from **Details**
- The result from [History](../history/index.md), including **Output**
- A log from [Diagnostics](../tools/diagnostics.md), if it's useful

Read logs before sharing them, because they can include what apps wrote there. Don't post your serial number or addresses.
