# Button problems

| Problem | What to do |
|---|---|
| **Nothing reached Bridgecoil** when listening | The button may not reach Android. See [Which buttons can be remapped](../buttons/which-buttons.md) |
| A press does two things | The button's normal action still happens. [Turn off the app it opens](../buttons/replace-what-a-button-opens.md) |
| A mapping stopped working | Open Buttons. If it says **The listener isn't running on the TV.**, tap **Start it again** |
| It stopped after a restart | Finish [TV setup](../get-started/set-up-your-tv.md), or see [TV setup problems](setup-problems.md) |
| There's a delay | The action fires 0.2 seconds after you let go, and the app then has to open |
| A hold also does the press action | Android's own handling of that button still happens on release |
| The wrong button fires | Remap it. Some remotes reuse a code on different devices |
| "That button already has a mapping." | Change that mapping instead of adding another |

A mapping that opens a disabled or removed app shows "The TV saw the press but couldn't open {label}." when you [test it](../buttons/test-pause-remove.md).
