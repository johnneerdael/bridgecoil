# Browse and search your apps

<p class="lead">The Apps page lists what's on the selected profile, 32 at a time as you scroll.</p>

!!! screenshot "apps-list.png"
    Apps with ratings on, showing the group headers and badges.

The line under the toolbar shows the profile and how many apps match. If it adds **Some app details unavailable**, the TV didn't give Bridgecoil every name or icon, and you'll see the package ID instead.

## Filter the list

Use the dropdown to choose **All apps**, **User apps**, **System apps**, **Disabled** or **Removed for profile**. System apps came with the TV. **Removed for profile** lists apps you've removed but which Android still keeps, so you can bring them back.

## Search

Type in **Find an app** and tap **Search**. It matches the name or package ID anywhere in the text, and capitals don't matter. To clear a search, empty the box and search again.

## How the list is ordered

Without ratings, the list is sorted by name. With [ratings](ratings.md) on, it's grouped in a fixed order, with a count on each group: **Installed by you**, **Recommended**, **Advanced**, **Not rated**, **Expert** and **Unsafe**. The Unsafe group starts collapsed, so you can't change those apps by accident. Tap its header to open it.

While your phone's keyboard is open, the list hides to make room, so close the keyboard to see your results.

If the list can't load, you'll see the error with **Retry loading apps**. "No apps match this view." means nothing fits the filter and search.

Tap any app to open its [details](turn-off-or-remove-an-app.md).
