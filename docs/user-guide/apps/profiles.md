# Choose a TV profile

<p class="lead">A TV can have several profiles, and app changes apply to one at a time.</p>

Most TVs have a single profile, so you can skip this page. A TV with a kids' profile, for example, has more than one.

Tap the profile tile on the Device page to open **Target profile**. Each row shows a name and whether it's running. Choosing one tells Bridgecoil where app actions apply. It doesn't switch the profile shown on the TV.

!!! screenshot "device-target-profile.png"
    The Target profile dialog with two profiles.

Changing profile starts a new session. Open reviews and a chosen APK file are dropped, and the Apps filter and search reset.

An app disabled in one profile stays as it was in the others. **Remove from profile** works the same way.
