# Change hidden settings

<p class="lead">Five Android settings that a TV often hides, with a review and undo for each.</p>

Open **Tools → Settings**. Each row shows its current value. Pick a new one and a review opens straight away. Bridgecoil reads the value back afterwards, and you can undo it from [History](../history/undo-a-change.md).

!!! screenshot "settings-page.png"
    Settings with Window animation and Transition animation.

| Setting | What it changes | Values | Applies to |
|---|---|---|---|
| **Window animation** | How long windows take to open | 0, 0.5, 1, 1.5, 2, 5, 10 | The whole TV |
| **Transition animation** | How long screens take to change | 0, 0.5, 1, 1.5, 2, 5, 10 | The whole TV |
| **Animator duration** | How long animations inside apps last | 0, 0.5, 1, 1.5, 2, 5, 10 | The whole TV |
| **Brightness** | Screen brightness | 0, 32, 64, 128, 192, 255 | This profile |
| **Media volume** | The stored media volume | 0, 3, 5, 8, 10, 15 | This profile |

Setting all three animations to 0 or 0.5 makes a slow TV feel quicker. 0 turns them off.

**Current** shows **Not set** if Android has no stored value, which usually means the default is in use. Firmware can ignore a stored value, so check the TV.

More settings are available in [Commands](commands.md).
